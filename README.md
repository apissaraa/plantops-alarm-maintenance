# PlantOps — Alarm & Maintenance Management System

## 1. รายละเอียดโครงงาน
PlantOps เป็นเว็บแอปพลิเคชันต้นแบบสำหรับจำลองการควบคุมเครื่องจักรในโรงงานอุตสาหกรรม ตรวจสอบสถานะเครื่องจักร แจ้งเตือนเหตุขัดข้อง และจัดการใบงานซ่อมบำรุง โดยใช้ฐานข้อมูล Supabase

**เว็บไซต์:** https://plantops-alarm-maintenance.vercel.app/

## 2. ความสามารถของระบบ
- **Dashboard:** แสดงภาพรวมจำนวนเครื่องจักร สถานะการทำงาน Alarm และใบงานซ่อม
- **Machine Master:** เพิ่ม แก้ไข และลบข้อมูลเครื่องจักรโดย Admin
- **Machine Simulator:** จำลองการสั่ง Start, Stop, Trigger Alarm และ Reset
- **Alarm Log:** แสดงประวัติการแจ้งเตือน รับทราบเหตุ และปิด Alarm
- **Maintenance:** สร้างใบงานซ่อมบำรุงและปรับสถานะงาน
- **Authentication:** เข้าสู่ระบบและออกจากระบบด้วย Supabase Auth
- **Role-Based Access Control:** แบ่งสิทธิ์ผู้ใช้งานเป็น Admin และ Technician
- **Database:** บันทึกข้อมูลเครื่องจักร Alarm และใบงานซ่อมลง Supabase

## 3. เทคโนโลยีที่ใช้
- Next.js / React / TypeScript
- Tailwind CSS
- Supabase Database และ Authentication
- Git และ GitHub
- GitHub Actions
- Vercel สำหรับเผยแพร่เว็บไซต์
- Visual Studio Code

## 4. วิธีใช้งาน
1. เปิดเว็บไซต์ PlantOps
2. เข้าสู่ระบบด้วยบัญชีทดสอบที่ได้รับ
3. ดูภาพรวมระบบที่ Dashboard
4. ไปหน้าเครื่องจักรเพื่อทดลองควบคุมเครื่องจักรจำลอง
5. ตรวจสอบเหตุขัดข้องที่ Alarm Log
6. สร้างและติดตามใบงานที่หน้า Maintenance

## 5. รายงานการใช้ AI ในการพัฒนาโครงงาน

**เครื่องมือ AI ที่ใช้:** ChatGPT

### วัตถุประสงค์
ใช้ AI เป็นผู้ช่วยในการวางแผน ออกแบบ พัฒนา ตรวจสอบข้อผิดพลาด และจัดทำเอกสารประกอบโครงงาน

### ขั้นตอนการใช้ AI
1. **วิเคราะห์ระบบ:** ช่วยกำหนดฟังก์ชันที่จำเป็น เช่น Dashboard, Simulator, Alarm Log และ Maintenance
2. **พัฒนาเว็บไซต์:** ช่วยแนะนำโครงสร้างโปรเจกต์และตัวอย่างโค้ดด้วย Next.js และ TypeScript
3. **ออกแบบฐานข้อมูล:** ช่วยวางแผนตารางและการเชื่อมต่อ Supabase
4. **จัดการสิทธิ์ผู้ใช้:** ช่วยแนะนำการใช้ Authentication และการแบ่งสิทธิ์ Admin / Technician
5. **ตรวจสอบข้อผิดพลาด:** ช่วยวิเคราะห์ข้อความ Error และแนะนำวิธีแก้ไขระหว่างพัฒนาและ Deploy
6. **เผยแพร่เว็บไซต์:** ช่วยแนะนำการใช้ GitHub และ Vercel
7. **จัดทำเอกสาร:** ช่วยเรียบเรียง README และสรุปผลการพัฒนา

### ผลลัพธ์จากการใช้ AI
สามารถพัฒนาเว็บต้นแบบที่มีระบบเข้าสู่ระบบ การจัดการข้อมูลเครื่องจักร การจำลอง Alarm และการจัดการใบงานซ่อมบำรุง โดยเชื่อมต่อฐานข้อมูลและเปิดใช้งานผ่านเว็บไซต์ได้

### ข้อจำกัด
ระบบนี้เป็นต้นแบบสำหรับการศึกษา ใช้ข้อมูลและเครื่องจักรจำลอง ยังไม่ได้เชื่อมต่อกับ PLC หรือเครื่องจักรจริง และต้องมีการทดสอบเพิ่มเติมก่อนนำไปใช้ในโรงงานจริง

## 6. สรุป
โครงงาน PlantOps แสดงแนวทางการนำเว็บแอปพลิเคชันและฐานข้อมูลมาประยุกต์ใช้กับการติดตามสถานะเครื่องจักร การแจ้งเตือน และการจัดการงานซ่อมบำรุงในระบบการผลิตอัตโนมัติ
